I am a Computer Science student (although I've been programming as my main hobby since 2017, now) that loves thinking about CS concepts like programming language design and machine learning.

It doesn't look like I do much but that's mostly because I work on a project, get demotivated, and then switch to something else and never post my WiP code as I usually wait until it's to a good enough state to publish before putting it here…

I have developed pretty strict standards on what I want in code (and I try to follow them myself), like:
- Making code easy to read:
  - Detailed naming (no single-letter variable names or abbreviations)
  - Avoiding implicitness (e.g. through the usage of keyword arguments)
  - Splitting out functions / methods early to allow you to assign names to them
- Expressive types to make error states unrepresentable
- Message-based concurrency ([Actors](https://en.wikipedia.org/wiki/Actor_model))

I will be disappointed in you if you use neural networks for anything other than information extraction / processing (y'know, like we've been using them for like 20 years before everyone went insane and decided that relying on weighted random number generators to think for them is a good idea). I doubt I have to worry about it here, but **don't send me AI-generated content.**
